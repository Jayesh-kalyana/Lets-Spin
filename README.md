**# Let's Spin**



\*\*Take a Chance. Bet Your Luck.\*\*



A 2D slot machine game developed in Unity as a game development assignment.



**## Project Overview**



Let's Spin is a 2D slot machine game built with Unity and C#. The game features three independently animated reels, a betting system, random outcomes, winning combinations, payout multipliers, audio feedback, and a WebGL build.



The project was developed with a focus on clean gameplay logic, simple UI interaction, smooth reel animation, and browser-based gameplay.



**## Features**



\- Three independently animated slot reels

\- Randomized reel results

\- Smooth reel spinning and stopping

\- Three-symbol matching wins

\- Two-adjacent-symbol partial wins

\- Betting system with minimum bet validation

\- Balance management

\- Symbol-based payout multipliers

\- Win and loss feedback

\- Individual win sounds for different symbols

\- Reel spinning and stopping sound effects

\- Lever interaction

\- Space Bar support for spinning

\- One-time Space Bar gameplay hint

\- Exit confirmation system

\- Background music

\- WebGL build



**## Controls**



\*\*Space Bar\*\*  

Starts the slot machine spin.



\*\*Lever\*\*  

Click the lever to start the spin.



\*\*Mouse\*\*  

Used for interacting with the UI and entering the bet amount.



**## Payout System**



\*\*Three Matching Symbols\*\*



\- Cherry: 1.5X

\- Bell: 2X

\- Seven: 2.5X

\- BAR: 5X



\*\*Two Adjacent Matching Symbols\*\*



\- Any matching adjacent pair: 1.25X



Two non-adjacent matching symbols do not count as a win.

**## WebGL Build**



The game includes a WebGL build that can be played directly in a web browser.



The WebGL build is included in the repository under the `WebGL` folder.



To run the game, open the WebGL build using a compatible local web server or WebGL hosting service.
